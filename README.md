# ระบบแจ้งซ่อมคอมพิวเตอร์และอุปกรณ์ของวิทยาลัย (Back-End)
- ชื่อ-รหัสนักศึกษา: <รักษ์ชัย ธรรมสุจริต-69319010043>
- รายวิชา: 31901-2005 การพัฒนาซอฟต์แวร์ด้วยเทคโนโลยี Back-End (สัปดาห์ที่ 1)

## คำอธิบายระบบ
บริการหลังบ้านสำหรับแจ้งซ่อมเครื่องคอมพิวเตอร์ในห้องปฏิบัติการ 8 ห้อง
ผู้แจ้งสร้างคำขอและติดตามสถานะ ช่างรับงานและบันทึกการซ่อม
หัวหน้างานมอบหมายงาน ดูสรุป และจัดการข้อมูลห้อง/เครื่อง
